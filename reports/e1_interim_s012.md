Main model: `cascade2`, the own-rate cascade (revision 3, DECISIONS D8; EXPERIMENT_PLAN section 12). The full-rate `cascade` (seed 0) and the parallel pairs are reported for reference; cascade2 - grm is exploratory (outside Holm). G3 applies to the parallel arms only.

Generated by `scripts/aggregate.py e1`. Points (x100). Subject-level: each person's confusion matrices summed over seeds (and folds where a person is tested by several fold models), paired subject bootstrap 10,000 resamples. All shifts are **within-database** (Sleep-EDF). ST is **development-grade**. Normalised gap = (oracle - transfer) / oracle, same test people; blank where no oracle exists or the oracle's subject set differs.

**INTERIM: seeds [0, 1, 2] only.** Not the confirmatory analysis (3 seeds).
